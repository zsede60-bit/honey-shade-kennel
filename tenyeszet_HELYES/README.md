# Honey Shade Kennel – tenyészet weboldal

A projekt Flask + SQLite alapú, helyben és egyszerű tárhelyen is futtatható.

## Indítás Windows alatt

```powershell
cd "$HOME\Desktop\tenyészet"
.\setup.ps1
.\run.ps1
```

Ha már van `.venv`, elég:

```powershell
.\run.ps1
```

## Admin

- Belépés: `http://127.0.0.1:5000/admin/login`
- Alapértelmezett felhasználó: `admin`
- Alapértelmezett jelszó: `LidiaAdmin2026!`

**Éles használat előtt kötelező megváltoztatni.**

## Admin funkciók

- weboldalszövegek szerkesztése
- képek feltöltése
- képek címének és sorrendjének módosítása
- képek törlése
- kiskutyák adatainak kezelése
- beérkezett kapcsolatfelvételek megtekintése/törlése

## Fontos

Az ÁSZF, adatkezelési tájékoztató, jogi nyilatkozat és impresszum szerkeszthető dokumentumként került be. A közzététel előtt a hiányzó hivatalos adatokat (különösen adószám/nyilvántartási adatok és tárhelyszolgáltató) ki kell tölteni.
